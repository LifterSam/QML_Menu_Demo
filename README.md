Hello,

this is a QML demonstration. It shows a menu page for a pad device with full functionality and calculation of all items shown.

In the directory `MenuDemoGitDeploy` is an executable file called `appIntroToQtQuickControls`. You can download the directory and
run it to test on your computer.


Key QML/Qt Quick Principles Demonstrated in this are:

° Reusable Components: Custom MenuItemAndPrice, MenuSection, and SpiceDial for modular UI.

° Reactive Bindings: Auto-updating totals (e.g., subtotal, totalOrderCost) via property dependencies.

° Layouts & Anchors: RowLayout/ColumnLayout for responsive design; precise positioning with margins.

° Styling & Theming: Central palette for colors, custom fonts, opacity layers, and image overlays.

° Interactive Controls: SpinBox, Slider, Dial, RadioButton with validation (e.g., order button logic).

° State Management: Timed transitions (Timer), visibility toggling, and feedback panels (BusyIndicator).

° Dynamic Features: Real-time pricing, spice customization, tip feedback, and simulated order flow.

There is some serious action in this small demo going on!
